# Формула

Адаптивное приложение на русском языке: обычный и научный калькулятор, построение одного или двух графиков, описание типовых преобразований функций и экспорт изображения в PNG.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер из папки проекта:

```sh
python -m http.server 8917
```

Затем перейдите на `http://localhost:8917`.

Сборка и установка пакетов не нужны. Для первоначальной загрузки требуются интернет-соединение: стили Tabler 1.7.4, math.js 14.8.1 и шрифты загружаются через CDN. Выражения разбираются ограниченным набором математических операций и функций, без `eval`.

В графиках поддерживаются `x`, `pi`/`π`, `e`, `sin`, `cos`, `tan`, `sqrt`, `cbrt`, `abs`, арифметика, степени и скобки. Тригонометрия графиков работает в радианах. В научном калькуляторе доступны переключение градусов и радиан. История хранится только в памяти страницы.

## Автотесты

После запуска сервера откройте `http://localhost:8917/tests/`. Набор `tests/suite.js` автоматически проведёт 23 интеграционные проверки в изолированном iframe: вычисления и ошибки, кнопки, историю, режимы углов, построение и перестроение графиков, описание преобразований, пиксели обеих линий в Canvas и экспортированном PNG, повторное использование рассчитанных точек и переключение темы. Результат и детали неудачных проверок выводятся на странице; также доступны в `window.__testResults` в консоли браузера. Для тестов требуется интернет-соединение для math.js.
