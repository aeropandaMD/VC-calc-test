# Техническая спецификация веб-приложения «Формула»

> **Статус документа:** описание фактически реализованной версии проекта на 13 ноября 2026 года.  
> **Назначение:** единый источник сведений о возможностях, интерфейсе, вычислительной логике, запуске, ограничениях и проверках.  
> **Область действия:** файлы текущего проекта; документ не является планом будущих функций.

## 1. Краткое описание

«Формула» — одностраничное русскоязычное веб-приложение для арифметических и научных вычислений и визуализации математических функций. Доступны три режима:

1. **Калькулятор** — базовые арифметические выражения.
2. **Научный калькулятор** — степени, корни, тригонометрия и выражения со скобками.
3. **Графики функций** — одна или две функции на общей координатной плоскости, настройка диапазона, описание распознаваемых преобразований и экспорт PNG.

Приложение работает в браузере без серверной вычислительной части, регистрации, сборки проекта и установки JavaScript-пакетов. Локальный сервер Python нужен для удобного запуска по HTTP; вычисления и построение графиков происходят на стороне браузера. Для загрузки внешних библиотек и шрифтов необходимо подключение к интернету.

### 1.2. Технологии и зависимости

- Стандартные HTML5, CSS и JavaScript; графики рисуются через **Canvas 2D**.
- **Tabler Core 1.7.4**: CSS с CDN `cdn.jsdelivr.net`, с атрибутами `integrity` и `crossorigin`. Применяются компоненты и классы карточек, кнопок, форм и уведомлений; оформление дополняется `styles.css`.
- **math.js 14.8.1**: браузерная сборка с CDN `cdn.jsdelivr.net` для разбора и компиляции математических выражений. Исполнение произвольного JavaScript через `eval` не используется.
- Шрифты **DM Sans** и **Manrope** загружаются с Google Fonts; в CSS предусмотрены резервные шрифты.
- Иконки встроены как SVG-символы непосредственно в `index.html`; отдельные файлы иконок не нужны.
- При запуске через `start.bat` требуется **Python 3** (`python` или `py -3`) со стандартным модулем `http.server`, а также Windows PowerShell для проверок порта. Отдельной базы данных, API и менеджера пакетов нет.

## 2. Интерфейс и навигация

### 2.1. Структура страницы

- На широком экране слева показана боковая панель с логотипом, переходами между режимами и информационным блоком; справа — верхняя панель и рабочая область.
- На узких экранах боковая панель скрывается, логотип переносится наверх, а режимы переключаются горизонтальными кнопками.
- Заголовок страницы, поясняющий текст, хлебная крошка и активное состояние навигации обновляются при смене режима.
- Общая кнопка переключает светлую и тёмную темы. Настройка темы действует в рамках текущей страницы и **не сохраняется** после её перезагрузки.
- В обоих режимах калькулятора рядом с основной панелью доступны история вычислений, подсказка и кликабельный пример.
- Режим графиков содержит панель параметров, Canvas с легендой и карточку описания преобразований под графиком.

### 2.2. Адаптивность

В `styles.css` предусмотрены контрольные точки около **1100, 850, 690, 600 и 480 px**:

- до 1100 px уменьшаются ширина боковой панели и отступы;
- до 850 px используется мобильная навигация вместо боковой панели;
- до 690 px основные панели калькулятора и графиков располагаются в один столбец;
- до 600 px дополнительные панели калькулятора также располагаются друг под другом;
- до 480 px уменьшаются отступы и размеры некоторых элементов; карточки описаний выводятся в один столбец, а кнопка экспорта может отображаться только иконкой с доступным именем.

Размер Canvas подстраивается под доступную область. При изменении её размеров график перерисовывается через `ResizeObserver`.

### 2.3. Доступность

- Поля ввода имеют подписи или доступные имена, кнопки со значками — `aria-label`/`title` там, где это необходимо.
- Результат калькулятора выводится через `output` с `aria-live="polite"`; ошибки — через блоки с `role="alert"`.
- Canvas имеет `role="img"` и текстовое `aria-label`; расположенная под ним легенда называет каждую функцию.
- Для вычислений поддерживаются клавиатура и экранные кнопки. Графики строятся отправкой формы, в том числе нажатием Enter внутри неё.

## 3. Общие правила математического ввода

### 3.1. Допустимые конструкции

Выражения разбираются средствами math.js, но до вычисления проходят проверку дерева разбора. Разрешены числовые константы, допустимые символы, скобки, арифметические операторы и, в научном режиме и графиках, поддерживаемые функции.

| Возможность | Обычный | Научный | Графики |
| --- | :---: | :---: | :---: |
| Числа, `+`, `-`, `*`, `/`, скобки | Да | Да | Да |
| Степень `^` | Нет | Да | Да |
| `sin`, `cos`, `tan` | Нет | Да | Да |
| `sqrt`, `cbrt`, `abs` | Нет | Да | Да |
| Константы `pi`/`π`, `e` | Да при вводе текста | Да | Да |
| Переменная `x` | Нет | Нет | Да |

Каждая поддерживаемая функция принимает **один аргумент**. В графиках поддерживается синтаксис неявного умножения math.js, например `2x+1`.

Перед разбором выполняется нормализация ввода:

- необязательное начальное `y =` удаляется;
- `×` и `·` заменяются на `*`, `÷` — на `/`, типографские минусы `−`/`–` — на `-`;
- `π` заменяется на `pi`, десятичная запятая — на точку.

Максимальная длина нормализованного выражения — **180 символов**. Присваивания, обращения к свойствам, массивы, неизвестные символы, другие функции и прочие конструкции вне разрешённого набора отклоняются. Это математический ввод, а не произвольный JavaScript.

### 3.2. Числовые результаты

- При отображении применяется русская локаль с десятичной запятой; результат округляется до 12 значащих цифр и выводится не более чем с 10 дробными знаками.
- Очень большие значения (от `10^12` по модулю) и малые ненулевые значения (менее `10^-7` по модулю) показываются в экспоненциальной записи.
- Значения с модулем менее `10^-12` отображаются как ноль; отрицательный ноль также нормализуется в ноль.
- Бесконечность, `NaN`, комплексные и другие нечисловые результаты не выводятся как корректный ответ.

## 4. Режим «Калькулятор»

### 4.1. Назначение и ввод

Режим открыт при первой загрузке страницы. Пользователь может вводить выражение с клавиатуры в текстовое поле или использовать экранные кнопки. Поддерживаются последовательности базовых операций и скобки при ручном вводе; порядок действий определяется синтаксисом выражения.

Экранная клавиатура содержит цифры, десятичный разделитель `,`, операции `+`, `−`, `×`, `÷`, а также:

| Кнопка | Действие |
| --- | --- |
| `AC` | Очищает поле и сбрасывает отображаемый результат в `0`. |
| `⌫` | Удаляет символ перед текущей позицией курсора; поддерживает выделение в поле. |
| `±` | Оборачивает текущее выражение в `-(...)`; при пустом поле вводит `-`. Это не переключатель знака отдельного операнда. |
| `%` | Дописывает `/100` в позицию курсора. Это деление на 100, а не контекстный «процент от предыдущего числа». |
| `=` | Вычисляет выражение и при успехе добавляет запись в историю. |

`Enter` вычисляет выражение, `Escape` очищает его. Кнопка примера в блоке подсказки подставляет и сразу вычисляет `128*4+36`.

### 4.2. Отображение и ошибки

При изменении поля или нажатии экранной кнопки приложение пытается показать предварительный результат. Для незавершённого или некорректного промежуточного выражения вместо него отображается `…`; явное нажатие `=`/Enter показывает `Ошибка` и пояснение. Для пустого поля при попытке вычисления выводится просьба ввести выражение. Деление на ноль, неверный синтаксис, неподдерживаемые функции и недопустимые математические результаты обрабатываются без технического стека ошибок в интерфейсе.

После успешного вычисления следующий ввод цифры или начала нового выражения через кнопки начинает новый ввод; ввод оператора может продолжить текущее выражение.

## 5. Режим «Научный калькулятор»

### 5.1. Возможности

Научный режим использует те же поле, результат, базовые кнопки и историю, что и обычный, а также дополнительный ряд кнопок:

`sin(`, `cos(`, `tan(`, `(`, `)`, `^`, `sqrt(`, `cbrt(`, `pi`, `e`.

Функция `abs` поддерживается математическим вводом, хотя отдельной экранной кнопки для неё нет. Примеры допустимых выражений: `(2+3)^2`, `sqrt(16)+cbrt(27)`, `sin(30)`.

### 5.2. Единицы угла

- **DEG** — режим по умолчанию; входные значения `sin`, `cos`, `tan` рассматриваются как градусы.
- **RAD** — входные значения рассматриваются как радианы.
- Переключение DEG/RAD обновляет предварительный результат текущего выражения.
- Для `tan` точки, где `|cos(угол)| < 10^-12`, считаются неопределёнными; например, `tan(90)` в DEG выдаёт ошибку области определения вместо искусственно большого числа.
- Переключатель угла относится к научному калькулятору; **графики всегда используют радианы**.

Кнопка примера научного режима подставляет и вычисляет `sin(30)+sqrt(16)`. Выбранная единица угла сохраняется при переключении режимов внутри открытой страницы, но не переживает её перезагрузку.

## 6. Режим «Графики функций»

### 6.1. Ввод и жизненный цикл

- Отдельные поля **«Функция 1»** (обязательна) и **«Функция 2»** (необязательна) принимают выражения с переменной `x`. Видимая приставка `y =` находится рядом с полем; пользователь может также ввести `y =` в самом выражении.
- Исходные значения: первая функция `x^2`, вторая пустая, диапазон X от `-10` до `10`.
- При первом переходе в режим строится график первой функции. Нажатие **«Построить график»** перестраивает изображение по текущим полям и диапазону.
- Если заданы обе функции, они отображаются одновременно. Если удалить текст второй функции после успешного построения, приложение автоматически пытается перестроить оставшийся первый график без нажатия кнопки.
- Изменение первой функции, заполнение второй или изменение диапазона сами по себе **не перестраивают** график: требуется нажать кнопку или отправить форму.
- При ошибке нового построения выводится сообщение, а данные последнего успешного построения и ранее нарисованный график не подменяются частичным результатом.

### 6.2. Допустимый диапазон

Обе границы X обязательны и должны быть конечными числами. Требуется `Xmin < Xmax`. Допустимая ширина диапазона: от `0,00000001` до `100 000 000` включительно. Некорректный, пустой, нулевой или обратный диапазон вызывает сообщение об ошибке. При двух функциях обе получают один и тот же диапазон X и единый масштаб Y.

### 6.3. Расчёт и отрисовка

1. При построении каждая функция вычисляется в **1201 равномерно расположенной точке** выбранного диапазона X (1200 интервалов). Точки и масштаб сохраняются в памяти до следующего успешного построения.
2. Значения вне области определения и нечисловые значения учитываются как пропуски. Если у функции нет ни одной определённой точки на сетке, построение не принимается. Частично определённые функции, например `sqrt(x)` на `[-10; 10]`, допускаются.
3. Для масштаба Y значения обеих функций объединяются, сортируются, берутся приблизительно 2-й и 98-й процентили, затем добавляется запас 12% сверху и снизу. Такой выбор помогает не «сплющивать» основную часть графика около асимптот; **крайние значения могут быть обрезаны**.
4. Рисуются сетка, числовые подписи, оси X/Y и линии функций. Шаг подписей выбирается автоматически с учётом диапазона и размера области.
5. Первый график — синий (`#5269ed`), второй — оранжевый (`#ec9b59`). Под Canvas находится легенда с цветом и введённой формулой.
6. Между нечисловыми точками, значениями с модулем более `10^15` и слишком резкими переходами линия разрывается, чтобы не соединять части графика через очевидные асимптоты.

При изменении размеров области, переключении темы и экспорте используются сохранённые точки: математические функции повторно не вычисляются. При смене темы меняются цвета поверхности, сетки и подписей; цвета линий функций остаются различимыми.

### 6.4. Описание преобразований

Для каждого успешно построенного графика под изображением выводится отдельная карточка. Описание автоматически определяется **только для распознаваемых выражений**, близких к виду `a · f(b(x − h)) + k`, где основа `f` — линейная, степенная, тригонометрическая, корневая функция или модуль. При наличии распознаваемых изменений могут быть названы:

- сдвиг вправо/влево и вверх/вниз;
- растяжение или сжатие по горизонтали и вертикали;
- отражение относительно оси X и/или Y.

Для неподходящего синтаксического дерева, например суммы разных семейств функций `x^2+sin(x)`, выводится честное сообщение о том, что автоматическое определение преобразований недоступно. **График при этом всё равно строится**, если функция допустима. Описание не является универсальным движком символьной алгебры: математически эквивалентные записи могут распознаваться по-разному.

### 6.5. Экспорт

Кнопка **«Скачать PNG»** сохраняет файл `formula-graph.png`. Изображение создаётся на отдельном Canvas с логическим размером **1000 × 620** и коэффициентом пиксельной плотности `devicePixelRatio × 2`. В него входят фон, координатная сетка, оси и все функции последнего успешного построения в общем масштабе. Легенда и текстовое описание, размещённые за пределами Canvas, **в PNG не включаются**.

## 7. История, состояние и хранение данных

- В историю добавляются только успешные вычисления обычного и научного калькуляторов после `=`/Enter или кнопки примера.
- Запись содержит исходное выражение, результат, режим и время (часы и минуты по русской локали).
- Максимум — **12 последних записей**; новые располагаются сверху.
- Нажатие на запись переключает калькулятор в соответствующий режим и возвращает выражение в поле. Кнопка удаления очищает всю историю.
- История, выбранный угол, тема и построенные графики находятся **только в оперативной памяти открытой страницы**. После обновления вкладки они сбрасываются; `localStorage`, cookies и серверное хранение не используются.
- При переключении между режимами калькулятора поле выражения и отображаемый результат очищаются. Графические поля и последний успешный график при возвращении в режим графиков сохраняются до перезагрузки страницы.

## 8. Обработка ошибок и безопасность ввода

| Ситуация | Текущее поведение |
| --- | --- |
| Пустое выражение калькулятора при вычислении | Показать просьбу ввести выражение. |
| Деление на ноль / нечисловой результат | Показать `Ошибка` и понятное сообщение. |
| Не закрыта скобка, нарушен синтаксис | Показать ошибку ввода, без технического стека. |
| Неизвестная функция, переменная или неподдерживаемая конструкция | Отклонить выражение при проверке дерева разбора. |
| Выражение длиннее 180 символов | Отклонить с указанием ограничения. |
| Корень отрицательного числа или неопределённая точка `tan` | Показать ошибку области определения в калькуляторе; пропустить соответствующую точку графика. |
| Пустая первая функция | Не начинать новое построение, показать сообщение. |
| Пустая вторая функция | Допустимый случай: строить только первую функцию. |
| Функция не определена ни в одной из 1201 точек | Не принимать новое построение, назвать номер функции. |
| Ошибочный диапазон X | Не принимать новое построение, объяснить проблему с границами. |
| math.js не загружена | Показать просьбу проверить интернет-соединение и обновить страницу при попытке вычислить/построить. |

Проверка по допустимым типам узлов и именам функций ограничивает математический синтаксис. Выражения пользователя не вставляются как HTML в историю и легенду: для этих данных применяется вывод через `textContent`. Приложение не посылает введённые формулы на собственный сервер; однако для загрузки сторонних ресурсов браузер обращается к указанным CDN.

## 9. Запуск и остановка на Windows

### 9.1. Рекомендуемый запуск

Запустите `start.bat` из папки проекта (двойным щелчком или из терминала). Скрипт:

1. Переходит в папку, где лежит сам `.bat`, и проверяет наличие `index.html`, `app.js`, `styles.css`.
2. Проверяет доступность PowerShell.
3. Проверяет, не обслуживается ли уже сайт на `127.0.0.1:8917`: если обслуживается, **не запускает второй сервер** и открывает страницу без дополнительной проверки Python.
4. Если порт занят другим сервисом, сообщает об ошибке и не подменяет чужой сайт.
5. При свободном порте проверяет Python 3 с `http.server` (`python`, затем `py -3`) и запускает `python -m http.server 8917 --bind 127.0.0.1 --directory "<папка проекта>"` в отдельном свёрнутом окне.
6. Ожидает готовности страницы, проверяя HTTP-ответ и признаки именно этого приложения, после чего выводит и открывает **[http://127.0.0.1:8917/](http://127.0.0.1:8917/)**.

Адрес `127.0.0.1` означает доступ только с данного компьютера. Скрипт не предназначен для публикации сайта в интернете.

### 9.2. Ручной запуск

При наличии Python 3 из папки проекта можно выполнить:

```sh
python -m http.server 8917
```

После этого открыть [http://localhost:8917/](http://localhost:8917/). Ручной вариант исторически использовался для проверки сайта, но его аргументы отличаются от аргументов `start.bat`; **`stop.bat` намеренно не завершает такой процесс автоматически**.

### 9.3. Безопасная остановка

Запустите `stop.bat`. Он проверяет владельца TCP-порта **8917**, адрес прослушивания `127.0.0.1`, имя процесса `python.exe`, аргументы `-m http.server 8917 --bind 127.0.0.1 --directory` и совпадение каталога с текущим проектом. Перед завершением повторно проверяются PID, время создания процесса, командная строка и факт прослушивания порта. Останавливается **только проверенный процесс сервера**; браузер, родительские оболочки и другие экземпляры Python не завершаются.

Если сервер уже остановлен, повторный запуск `stop.bat` успешен и не меняет состояние системы. При чужом владельце порта скрипт отказывается завершать процесс. После штатной остановки проверяется освобождение порта. Для работы проверок требуется Windows PowerShell.

## 10. Автоматические проверки

После запуска сервера открыть **[http://127.0.0.1:8917/tests/](http://127.0.0.1:8917/tests/)**. Страница `tests/index.html` загружает приложение в iframe и автоматически запускает `tests/suite.js`; результат отображается в браузере и доступен как `window.__testResults`.

**23 интеграционные проверки** охватывают:

- приоритет операций, отрицательные и дробные числа;
- экранные кнопки, историю и восстановление выражения;
- деление на ноль, ошибки синтаксиса, длину ввода и недопустимые конструкции;
- степени, корни, тригонометрию в DEG/RAD и точки разрыва `tan`;
- один и два графика, удаление второй функции и перестроение;
- оба цвета линий в пикселях Canvas и экспортированного PNG;
- допустимые и ошибочные диапазоны, частичные области определения;
- отдельные описания преобразований и сообщение для нераспознанных форм;
- отсутствие повторных вычислений функции при смене темы и экспорте;
- переключение режимов/темы и отсутствие ошибок JavaScript во время прогона.

Тесты выполняются **в браузере**, а не как команда `npm test`; они также требуют загрузки math.js из сети. Последний зафиксированный прогон после оптимизации графиков: **23 из 23 проверок успешно**. Этот факт не заменяет нового прогона после будущих изменений.

## 11. Известные ограничения и границы реализации

1. Это статическое клиентское приложение: нет учётных записей, синхронизации истории, серверного API, режима совместной работы и сохранения состояния между перезагрузками.
2. Без доступа к CDN библиотека math.js не загружается и математические операции не работают; внешний CSS и шрифты также требуют сети.
3. Кнопка `%` означает добавление `/100`, а не контекстное вычисление процентов; `±` оборачивает **всё** выражение, а не последний операнд.
4. Автоматическое описание преобразований покрывает только поддерживаемые формы записи. Для сложных сумм и иных комбинаций предусмотрено сообщение о невозможности определения.
5. График — дискретная аппроксимация по 1201 точке. Узкие особенности между точками могут не отобразиться; экстремальные значения могут отсекаться выбранным масштабом Y.
6. Экспортируется только графический Canvas: текстовые карточки, легенда и элементы управления в PNG не входят.
7. Нет интерактивного панорамирования, масштабирования колёсиком, маркеров точек, поиска пересечений или экспорта формул/истории.
8. `stop.bat` останавливает только сервер, запущенный **точной командой из `start.bat`** для данной папки; это сознательная защита от завершения чужих процессов.

## 12. Критерии проверки текущей версии

Версия соответствует этой спецификации, если:

- все три режима доступны из одной страницы и работают на компьютере и узком экране;
- базовые и научные выражения вычисляются, а ошибки не приводят к падению интерфейса;
- одна и две функции строятся в едином масштабе с разными цветами и легендой;
- изменение диапазона после нажатия кнопки перестраивает обе функции;
- под графиками присутствуют отдельные описания либо явное уведомление о невозможности их определить;
- экспортированный PNG содержит обе линии, когда заданы две функции;
- `start.bat` запускает или повторно открывает сайт на порту 8917, а `stop.bat` безопасно останавливает только принадлежащий проекту сервер;
- страница тестов показывает успешное прохождение всех 23 проверок.
